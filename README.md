# Fleet-emissions-compliance-toolkit
Validating ship noon-report data and estimating CO₂, CII and EU ETS exposure (synthetic data)
## The problem
Ships send daily "noon reports" with fuel use and distance, often typed by hand.
Errors in this data lead to wrong emissions reporting, wrong EU carbon costs
and surprise climate ratings. Today, much of this checking is done manually.

## What this project does (in progress)
A tool that checks noon-report data for errors, then estimates each ship's
CO₂ emissions, CII rating and EU ETS cost.

*All data in this project is synthetic. No real company data is used.*
